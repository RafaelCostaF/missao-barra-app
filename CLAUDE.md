## Layout (npm workspaces)
- `packages/core` — all logic, framework-free, injected deps: `signal.ts` (stale >2min), `geo.ts` (haversine, accuracy filter, `toFix`), `queue.ts` (persistent offline position queue, backoff), `tracking.ts` (tracker: consent→tracking→finished; auto-stops GPS on server "not tracking"), `logger.ts` (sanitizes secrets/coords, offline buffer → log-ingest), `notifications.ts` (`toNotice`), `api.ts` (supabase-js data layer), `report.ts` (summary, CSV, `SESSION_ACTIONS`), `crowd.ts` (route distribution + attention outliers), `audit.ts` (report KPIs, funnel, formatters), `run.ts` (runner metrics from device fixes via `tracker.stats`: current/avg/moving pace, splits, `routeProgress`/`currentKm` on official km scale, `routeEtas` next checkpoint + finish ETA, `nearbyRunners`, `racePosition`), `people.ts` (per-person flags/filters, search, tel/WhatsApp/Maps links), `directory.ts` (all-accounts directory filters/sort/stats, `parseDateTimeBR`/`maskDateTimeBR` for typed dates in the app).
- `apps/mobile` — Expo SDK 58, expo-router (`src/app`), `src/lib/{services,location,bootstrap}.ts`. Single session screen `src/app/session/[id].tsx` for both kinds (fixed bottom bar while tracking: hold-1s Emergência, Ajuda, Finalizar; metrics first, map collapsible; runner dashboard `components/RunPanel.tsx`: big pace — average from server start time on open, current after ~30 s — distance/time, next checkpoint + finish with ETA/arrival clock, race position, nearby runners ahead/behind within 2 km, km splits, GPS accuracy/battery/unsent queue; official consent text says position is visible to other participants); form `components/ProfileForm.tsx` used by tab `profile.tsx` and stack route `cadastro.tsx` (opened from a session, has back button; photo via `lib/photo.ts`, masked phone with DDD — no SMS for now, emergency/health, sign out). `Input` takes `label`/`hint`; iOS `KeyboardBar` (OK over numeric keyboard) mounted once in root layout; battery sent with each position batch (`expo-battery`). Expo Go has no background GPS → `location.ts` falls back to `watchPositionAsync` + keep-awake. Android without `GOOGLE_MAPS_API_KEY` shows list instead of map (`LiveMap.tsx`). Home tab (`index.tsx`, no header) opens with `BrandHero` (lighthouse logo from `@mb/ui-tokens/icons/icon-512.png`, rotating beam, name, motto, next-event countdown; `compact` on login). Admin parity: tab `(tabs)/admin.tsx` ("Organização", shown only if role admin via `useIsAdmin`) = open alerts + events + shortcuts; stack routes `src/app/admin/*` (event-new, event/[id] with the 5 web tabs in `components/admin/EventTabs.tsx` + `RouteEditor.tsx` long-press/drag/“minha posição”, participant, people, person/[id], staff, logs); kit `components/admin/kit.tsx` (CSV via system Share).
- `apps/admin` — Vite + React + Leaflet, hash routes: events CRUD/lifecycle, route editor, live map/alerts/summary, logs+CSV. Pages Eventos/Pessoas (`People.tsx`: directory with KPIs, filters by name/e-mail/phone, role, profile, min events/races, activity, never participated; sort; CSV; profile modal with history + grant/revoke admin)/Equipe (+ permission history)/Logs.
